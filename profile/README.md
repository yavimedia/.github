## What we do

- **Meta Ads and Google Ads** built around how homeowners buy kitchen, bathroom, basement and full-home renovation work.
- **AI appointment booking** that replies to new inquiries fast and books the estimate, so the owner is not tied to the phone.
- **One contractor per city**, so we never run ads for your competitor down the road.
